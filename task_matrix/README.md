# Life RPG — Матрица квестов

«Как бы выглядела моя жизнь, если бы я воспринимал её игрой» — десктопное приложение для Windows,
которое превращает дела в **квесты**, распределяет их по **значимости** и **сложности** на четыре зоны
и награждает за выполнение **опытом, уровнями и достижениями**.

| | Сложность ≤ 2 | Сложность ≥ 3 |
|---|---|---|
| **Значимость ≥ 3** | ⚡ Сделать сейчас | 🗺️ Запланировать |
| **Значимость ≤ 2** | 🍃 Между делом | 💤 Отложить |

## Игровая механика

- **Опыт (XP).** За каждый выполненный квест: `10 + 8 × значимость + 12 × сложность` — от 30 до 110 XP.
  Выполнили до срока — **+20 %**. Сняли галочку — опыт за квест забирается обратно.
  Удаление выполненного квеста опыт **не** отнимает (он хранится в журнале).
- **Уровни и звания.** До 2-го уровня нужно 100 XP, дальше каждый уровень на 50 XP дороже.
  Звания: Новичок → Ученик → Искатель приключений → Боец → Ветеран → Мастер → Герой → Легенда.
- **Навыки.** Каждый квест качает один навык: 💪 Сила, 🧠 Интеллект, 💼 Карьера, ❤️ Здоровье,
  🗣️ Харизма, 🏠 Быт, 🎨 Творчество, ✨ Разное. У каждого навыка свой уровень.
- **Редкость** квеста зависит от сложности: Обычный → Необычный → Редкий → Эпический → Легендарный.
- **Задание дня.** Выполните N квестов за день (по умолчанию 3, меняется в настройках) — бонус +50 XP.
- **Серия.** Сколько дней подряд вы выполняете хотя бы один квест.
- **Достижения.** 14 штук: «Первый шаг», «Победитель дракона» (легендарный квест), «Неделя силы» (серия 7 дней) и другие.
- **Уведомления.** «+78 XP», «НОВЫЙ УРОВЕНЬ!», «Достижение!» всплывают в правом нижнем углу.
- **Вкладка «Персонаж»:** аватар, уровень, график опыта за 14 дней, навыки, журнал и все достижения.

Все числа баланса собраны в `app/game.py` — их можно менять как угодно.

Стек: Python 3.11+, PySide6 (Qt), SQLite, PyInstaller.

## 1. Установка Python

1. Скачайте Python 3.11 или новее с сайта <https://www.python.org/downloads/windows/>.
2. Запустите установщик и **обязательно отметьте галочку «Add python.exe to PATH»** внизу первого окна.
3. Нажмите «Install Now».
4. Проверьте установку: откройте «Командную строку» (Win+R → `cmd`) и выполните:

```bash
python --version
```

Должно появиться, например, `Python 3.12.4`.

## 2. Запуск приложения

Откройте командную строку в папке `task_matrix` (в Проводнике: щёлкните по адресной строке, введите `cmd` и нажмите Enter).

Рекомендуется создать виртуальное окружение, чтобы библиотеки не смешивались с системными:

```bash
python -m venv .venv
```

```bash
.venv\Scripts\activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите приложение:

```bash
python main.py
```

## 3. Сборка .exe через PyInstaller

Самый простой способ — дважды щёлкнуть по файлу `build_exe.bat`.

Или вручную (в той же командной строке, с активированным окружением):

```bash
pyinstaller --noconfirm --onefile --windowed --name TaskMatrix main.py
```

- `--onefile` — всё в одном файле;
- `--windowed` — без чёрного окна консоли;
- `--name TaskMatrix` — имя итогового файла.

Готовый файл появится в `dist\TaskMatrix.exe`. Его можно скопировать куда угодно — Python на целевом компьютере не нужен.
Первый запуск однофайлового .exe занимает несколько секунд: программа распаковывается во временную папку.

## Где хранятся данные

База данных лежит в папке пользователя, а не рядом с программой:

```
%APPDATA%\TaskMatrix\tasks.db
```

(обычно `C:\Users\<Имя>\AppData\Roaming\TaskMatrix\tasks.db`). Путь также показан в окне «Настройки».
Чтобы перенести задачи на другой компьютер, скопируйте этот файл. Для тестов путь можно подменить переменной окружения `TASKMATRIX_DB`.

## Как пользоваться

- **＋ Новый квест** или **Ctrl+N** — создать квест (выберите навык — увидите награду и редкость).
- **Двойной клик по карточке** — редактировать.
- **Кружок на карточке** — завершить квест и получить опыт.
- **Перетаскивание карточки** в другую зону — значимость и сложность меняются автоматически, минимально: например, задача (значимость 5, сложность 1), перенесённая в «Запланировать», станет (5, 3).
- **Правый клик** по карточке или строке таблицы — меню с удалением (с подтверждением).
- **Клик по карточке + Delete** — удалить выделенную задачу.
- **Двойной клик по заголовку зоны** (или кнопка ⤢) — раскрыть зону на всё окно; повторно — свернуть.
- **Вкладка «Все квесты»** — таблица: сортировка кликом по заголовку столбца, фильтр «Активные / Выполненные / Все», поиск по названию (**Ctrl+F**).
- **Просроченные задачи** (срок прошёл, не выполнены) подсвечиваются красным.
- **⚙ Настройки** — имя героя, аватар, цель задания дня, тёмная (игровая) или светлая тема.

## Структура проекта

```
task_matrix/
├── main.py                  # Точка входа: QApplication, русская локаль, тема, главное окно
├── requirements.txt
├── build_exe.bat            # Сборка .exe одной командой
└── app/
    ├── config.py            # ⚙ ПОРОГИ зон, названия, иконки и цвета зон, путь к базе
    ├── models.py            # Класс Task и логика зон (zone_for, fit_to_zone) — без Qt и SQL
    ├── game.py              # 🎮 Опыт, уровни, навыки, редкость, достижения — без Qt и SQL
    ├── database.py          # Все SQL-запросы: задачи, журнал опыта, достижения, настройки
    └── ui/
        ├── controller.py    # Посредник UI ↔ база + начисление опыта, уровни, достижения
        ├── hud.py           # Игровая панель в шапке: аватар, уровень, XP, серия, задание дня
        ├── toast.py         # Всплывающие анимированные уведомления
        ├── profile_view.py  # Вкладка «Персонаж»: график, навыки, журнал, достижения
        ├── widgets.py       # Мелкие элементы: чипы, круглый аватар, текст срока
        ├── main_window.py   # Главное окно, вкладки, меню, горячие клавиши
        ├── matrix_view.py   # Матрица 2×2 и зоны (приём drag & drop, раскрытие)
        ├── task_card.py     # Карточка квеста (награда, навык, редкость, срок, перетаскивание)
        ├── task_table.py    # Таблица «Все задачи»: модель, фильтр, сортировка
        ├── task_dialog.py   # Диалог задачи со слайдерами и календарём
        ├── settings_dialog.py  # Имя, аватар, задание дня, тема
        └── themes.py        # Цвета светлой/тёмной темы и таблица стилей
```

Поток данных: виджет → `TaskController` → `Database` → сигнал `tasks_changed` → матрица, таблица, HUD и профиль перечитывают данные из базы. Поэтому все представления всегда показывают одно и то же.

При выполнении квеста контроллер дополнительно пишет запись в журнал опыта (`xp_events`) и испускает сигналы `xp_gained`, `level_up`, `achievement_unlocked`, `daily_completed` — на них главное окно показывает уведомления.

База от первой версии приложения обновляется автоматически: добавляются новые поля, а уже выполненные задачи засчитываются в опыт.

## Как изменить правила распределения

Откройте `app/config.py`:

```python
IMPORTANCE_THRESHOLD = 3   # значимая, если значимость >= 3
DIFFICULTY_THRESHOLD = 3   # сложная, если сложность >= 3
```

Больше ничего менять не нужно — логика зон, перетаскивание и подсказки берут пороги отсюда.
