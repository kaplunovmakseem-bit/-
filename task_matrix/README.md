# Матрица задач

Десктопное приложение для Windows, которое распределяет задачи по **значимости** и **сложности** на четыре зоны:

| | Сложность ≤ 2 | Сложность ≥ 3 |
|---|---|---|
| **Значимость ≥ 3** | 🟢 Сделать сейчас | 🔵 Запланировать |
| **Значимость ≤ 2** | 🟡 Между делом | ⚪ Отложить |

Стек: Python 3.11+, PySide6 (Qt), SQLite, PyInstaller.

---

## 1. Установка Python

1. Скачайте Python 3.11 или новее с сайта <https://www.python.org/downloads/windows/>.
2. Запустите установщик и **обязательно отметьте галочку «Add python.exe to PATH»** внизу первого окна.
3. Нажмите «Install Now».
4. Проверьте установку: откройте «Командную строку» (Win+R → `cmd`) и выполните:

```bash
python --version
```

Должно появиться, например, `Python 3.12.4`.

## 2. Запуск приложения

Откройте командную строку в папке `task_matrix` (в Проводнике: щёлкните по адресной строке, введите `cmd` и нажмите Enter).

Рекомендуется создать виртуальное окружение, чтобы библиотеки не смешивались с системными:

```bash
python -m venv .venv
```

```bash
.venv\Scripts\activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите приложение:

```bash
python main.py
```

## 3. Сборка .exe через PyInstaller

Самый простой способ — дважды щёлкнуть по файлу `build_exe.bat`.

Или вручную (в той же командной строке, с активированным окружением):

```bash
pyinstaller --noconfirm --onefile --windowed --name TaskMatrix main.py
```

- `--onefile` — всё в одном файле;
- `--windowed` — без чёрного окна консоли;
- `--name TaskMatrix` — имя итогового файла.

Готовый файл появится в `dist\TaskMatrix.exe`. Его можно скопировать куда угодно — Python на целевом компьютере не нужен.
Первый запуск однофайлового .exe занимает несколько секунд: программа распаковывается во временную папку.

## Где хранятся данные

База данных лежит в папке пользователя, а не рядом с программой:

```
%APPDATA%\TaskMatrix\tasks.db
```

(обычно `C:\Users\<Имя>\AppData\Roaming\TaskMatrix\tasks.db`). Путь также показан в окне «Настройки».
Чтобы перенести задачи на другой компьютер, скопируйте этот файл. Для тестов путь можно подменить переменной окружения `TASKMATRIX_DB`.

## Как пользоваться

- **+ Новая задача** или **Ctrl+N** — создать задачу.
- **Двойной клик по карточке** — редактировать.
- **Чекбокс на карточке** — отметить выполненной.
- **Перетаскивание карточки** в другую зону — значимость и сложность меняются автоматически, минимально: например, задача (значимость 5, сложность 1), перенесённая в «Запланировать», станет (5, 3).
- **Правый клик** по карточке или строке таблицы — меню с удалением (с подтверждением).
- **Клик по карточке + Delete** — удалить выделенную задачу.
- **Двойной клик по заголовку зоны** (или кнопка ⤢) — раскрыть зону на всё окно; повторно — свернуть.
- **Вкладка «Все задачи»** — таблица: сортировка кликом по заголовку столбца, фильтр «Активные / Выполненные / Все», поиск по названию (**Ctrl+F**).
- **Просроченные задачи** (срок прошёл, не выполнены) подсвечиваются красным.
- **⚙ Настройки** — светлая или тёмная тема (выбор запоминается).

## Структура проекта

```
task_matrix/
├── main.py                  # Точка входа: QApplication, русская локаль, тема, главное окно
├── requirements.txt
├── build_exe.bat            # Сборка .exe одной командой
└── app/
    ├── config.py            # ⚙ ПОРОГИ зон, названия и цвета зон, путь к базе
    ├── models.py            # Класс Task и логика зон (zone_for, fit_to_zone) — без Qt и SQL
    ├── database.py          # Все SQL-запросы: создание схемы, CRUD, настройки
    └── ui/
        ├── controller.py    # Посредник UI ↔ база: создание, правка, удаление, перенос
        ├── main_window.py   # Главное окно, вкладки, меню, горячие клавиши
        ├── matrix_view.py   # Матрица 2×2 и зоны (приём drag & drop, раскрытие)
        ├── task_card.py     # Карточка задачи (чекбокс, начало перетаскивания, меню)
        ├── task_table.py    # Таблица «Все задачи»: модель, фильтр, сортировка
        ├── task_dialog.py   # Диалог задачи со слайдерами и календарём
        ├── settings_dialog.py  # Выбор темы
        └── themes.py        # Цвета светлой/тёмной темы и таблица стилей
```

Поток данных: виджет → `TaskController` → `Database` → сигнал `tasks_changed` → матрица и таблица перечитывают задачи из базы. Поэтому оба представления всегда показывают одно и то же.

## Как изменить правила распределения

Откройте `app/config.py`:

```python
IMPORTANCE_THRESHOLD = 3   # значимая, если значимость >= 3
DIFFICULTY_THRESHOLD = 3   # сложная, если сложность >= 3
```

Больше ничего менять не нужно — логика зон, перетаскивание и подсказки берут пороги отсюда.
