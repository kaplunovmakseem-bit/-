# Приоритеты — распределение задач по значимости и сложности

Android-приложение (Kotlin, Jetpack Compose, Material 3) в красных тонах.
Каждая задача автоматически попадает в одну из четырёх зон матрицы 2×2:

| | Сложность ≤ 2 | Сложность ≥ 3 |
|---|---|---|
| **Значимость ≥ 3** | 🔴 Сделать сейчас | 🟥 Запланировать |
| **Значимость ≤ 2** | 🩷 Между делом | 🟤 Отложить |

Пороги задаются в одном месте — `app/src/main/java/ru/taskpriority/domain/PriorityZone.kt`,
объект `ZoneThresholds`.

## Возможности

- **Матрица** — главный экран: 4 цветные зоны со счётчиком активных задач. Нажатие на зону открывает её на весь экран.
- **Все задачи** (иконка списка в шапке) — сортировка по значимости, сложности, сроку (стрелка меняет направление) и фильтр «Активные / Выполненные / Все».
- **Создание и редактирование** — название, описание, слайдеры значимости и сложности с подписями, выбор срока в календаре. Под слайдерами сразу видно, в какую зону попадёт задача.
- Галочка на карточке — отметить выполненной; свайп влево/вправо — удалить; в обоих случаях можно нажать «Отменить» в Snackbar.
- Светлая и тёмная тема (следует за настройкой системы).
- Задачи хранятся локально в базе Room.

## Структура проекта

```
app/src/main/java/ru/taskpriority/
├── TaskPriorityApp.kt        — Application: создаёт базу и репозиторий
├── MainActivity.kt           — точка входа: тема + навигация
├── data/                     — Room: Task (сущность), TaskDao, TaskDatabase, TaskRepository
├── domain/                   — PriorityZone + ZoneThresholds (пороги), порядок сортировки в зоне
└── ui/
    ├── theme/                — красная палитра, светлая/тёмная тема, цвета зон
    ├── components/           — карточка задачи, свайп-удаление, шапка зоны, форматирование дат
    ├── navigation/           — маршруты и граф навигации
    ├── matrix/               — главный экран (MatrixScreen + MatrixViewModel)
    ├── zone/                 — зона на весь экран
    ├── list/                 — список с сортировкой и фильтром
    └── edit/                 — создание/редактирование
```

Архитектура — MVVM: экран (Composable) читает `StateFlow` из ViewModel через
`collectAsStateWithLifecycle()` и передаёт ей действия пользователя;
ViewModel обращается к `TaskRepository`, который работает с Room.

## Как открыть проект в Android Studio

1. Установите [Android Studio](https://developer.android.com/studio) (последнюю стабильную версию).
2. Скачайте репозиторий: `git clone <адрес репозитория>` или «Code → Download ZIP» на GitHub и распакуйте.
3. В Android Studio: **File → Open** и выберите папку **`TaskPriority`** (именно её, а не корень репозитория).
4. Дождитесь окончания синхронизации Gradle (строка прогресса внизу). Если студия предложит
   установить недостающие компоненты SDK (Android 16 / API 36) — согласитесь.
5. Чтобы запустить на эмуляторе: **Tools → Device Manager → Create Device**, затем зелёная кнопка ▶ **Run 'app'**.

## Как собрать APK

**Из Android Studio:** **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
Когда сборка закончится, нажмите **locate** во всплывающем уведомлении.

**Из командной строки** (в папке `TaskPriority`, нужен JDK 17+ и Android SDK —
путь к SDK Android Studio сама пропишет в `local.properties`):

```bash
./gradlew assembleDebug        # macOS / Linux
gradlew.bat assembleDebug      # Windows
```

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

**Без установки чего-либо:** при каждом push GitHub Actions собирает APK.
Откройте вкладку **Actions** репозитория → последний запуск «Android build» →
блок **Artifacts** → скачайте `TaskPriority-debug-apk` (это zip, внутри APK).

## Как установить на телефон

**Способ 1 — по кабелю прямо из Android Studio**
1. На телефоне: **Настройки → О телефоне** → 7 раз нажмите на «Номер сборки» — включится режим разработчика.
2. **Настройки → Для разработчиков** → включите **Отладка по USB**.
3. Подключите телефон кабелем, подтвердите доступ на экране телефона.
4. В Android Studio выберите телефон в списке устройств и нажмите ▶ **Run**.

**Способ 2 — через adb**
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

**Способ 3 — просто файлом**
1. Перекиньте `app-debug.apk` на телефон (кабель, Telegram «Избранное», Google Диск и т.п.).
2. Откройте файл на телефоне. Android попросит разрешить установку из этого источника — разрешите.
3. Нажмите «Установить».

> Debug-APK подписан отладочным ключом — для личного использования этого достаточно.
> Требуется Android 8.0 (API 26) или новее.

## Как поменять пороги зон

Откройте `domain/PriorityZone.kt`:

```kotlin
object ZoneThresholds {
    const val HIGH_IMPORTANCE_FROM = 3  // значимость >= 3 — «высокая»
    const val HIGH_DIFFICULTY_FROM = 3  // сложность  >= 3 — «высокая»
}
```

Измените числа и пересоберите приложение — все экраны сразу начнут использовать новые пороги.
